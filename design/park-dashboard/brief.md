# 园区俯瞰图驾驶舱大屏设计 Brief

## 主题
园区智慧安防与战略物资管理驾驶舱大屏界面设计

## 核心对象
- 中间：园区俯瞰图大地图（AI 生成示意性科技园区鸟瞰图）
- 左侧：悬浮式战略物资设备总览面板（可收起）
- 右侧：悬浮式告警/事件日志面板（可收起）
- 顶部：居中大 Header 标题，两侧功能入口、天气、日期时间、日志入口

## 功能需求
1. 地图上标记园区摄像头位置（东南3摄像头等命名）
2. 地图上标记重要战略物资设备位置：消防栓、水井、电井房等
3. 顶部搜索框：输入点位名称快速定位到地图对应位置并放大居中
4. 点击地图上的设备 icon → 唤起该物资的基本信息卡片 + 操作入口
5. 信息卡操作："快定位" → 地图移动到该点位并放大居中
6. 支持拖拽更新战略设备、物资位置（视觉上体现拖拽交互）

## 视觉风格
- 深色政务/安防风：深蓝绿底色 + 金色/白色文字
- 科技感边框、发光效果、数据大屏风格
- 适合监控指挥中心场景

## 交付物
1. HTML 可交互大屏原型（1920x1080 固定画布）
2. MasterGo 设计稿（同步生成）

## 内容结构
### 顶部 Header
- 居中大标题："园区智慧管理驾驶舱"
- 左侧：Logo/系统名、天气信息
- 右侧：日期时间、系统日志入口、用户信息

### 左侧面板（战略物资设备总览）
- 可收起/展开
- 按类型分组：摄像头、消防栓、水井、电井房
- 每组显示数量、在线状态
- 点击某设备 → 地图定位
- 顶部搜索框（全局搜索点位）

### 右侧面板（告警/事件日志）
- 可收起/展开
- 时间流式事件列表
- 不同级别告警用不同颜色标识
- 显示时间、事件类型、位置描述

### 中间地图区域
- AI 生成的科技园区俯瞰图作为底图
- 叠加各类设备 icon（摄像头、消防栓、水井、电井房）
- 点击 icon 弹出信息卡片
- 支持缩放、拖拽

### 信息卡片（点击 icon 唤起）
- 设备名称
- 设备类型
- 位置描述
- 状态（在线/离线/异常）
- 操作按钮："快定位到中心"、"查看详情"

## 视觉方向
- 主色：深海军蓝/墨绿底色（#0a1628 ~ #1a3a4a 渐变）
- 强调色：金色/琥珀色（#d4a853 ~ #e8c97a）
- 辅助色：青色/蓝绿色（用于数据高亮、在线状态）
- 警告色：红色（告警）、黄色（注意）
- 文字：白色/浅金色为主
- 边框：半透明金色或青色发光边框
- 面板：深色半透明背景 + 细边框

## 素材需求
- 1 张 AI 生成的科技园区俯瞰鸟瞰图作为地图底图（俯视角度，包含建筑群、道路、绿化，夜景或黄昏感更适合深色大屏）
